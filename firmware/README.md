## 登记规范

每次新增/更新固件或参数：

1. 把二进制与参数文件放入本目录（大文件可用 `git-lfs` 或给出可信存放方式）。
2. 在 `../CHANGELOG.md` 顶部追加发布条目。
3. 在下方「版本登记」表补充一行，注明：日期、文件、变更、参数名是否有 **Breaking change**、验证状态、关联 Issue。
