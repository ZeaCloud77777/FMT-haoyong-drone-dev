项目概述

平台与技术栈

表 1 · 平台与技术构成
项目说明
硬件平台好用无人机（四旋翼），机载采用了 NVIDIA Nano 核心板，配套遥控器、GPS/RTK 基站、机载摄像头

地面站QGroundControl（QGC）＋ RTK 基站配置

开发目标

  1. 打通「FMT-SIM 仿真 → 半实物 → 实机」的一致开发链路；
  2. 支撑多机自主飞行、mission 航点飞行、异常注入与失效保护验证；
  3. 面向城市场景的空地/低空作业算法（含建图、目标跟踪）提供可复现的测试载体。

07

风险与注意事项

载荷超限 / 电机饱和
飞行测试系安全绳（约 2.2kg）明显超载，导致控制余量不足。建议改用轻量风筝线 + 卡扣方案，并在负载变更前评估载荷上限。
室内定位漂移
无动捕/RTK 时仅靠 IMU + 水平仪定位，定高模式不控位置，起飞易飘。建议室内环境先建立稳定定位源，或先做水平校准。
固件参数名变更
电机饱和固件改动了 FMS/CONTROL 参数名，若在飞控外部设置参数需同步改名，否则配置失效。
资料与安全
内部培训视频、问题清单与测试物料属于项目内部资料，仓库公开后应避免上传任何内部文档、地址与身份信息。
